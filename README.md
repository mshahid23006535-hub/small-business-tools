# Small Business Tools — Free Online Calculator Guide

A curated, independent guide to the best **free online calculators** for small business owners, covering pricing, marketing, finance, health, and everyday math.

**🔗 Live site:** [https://mshahid23006535-hub.github.io/small-business-tools/](https://mshahid23006535-hub.github.io/small-business-tools/)


---

## About

Small business owners run dozens of quick calculations every week — what to charge, whether an ad campaign is profitable, if a loan is affordable. This project is a hand-picked reference of the free web tools that answer those questions fastest, with the formulas behind them shown transparently.

Featured tools include:

| Category | Tool | What it solves |
|----------|------|----------------|
| Pricing | Margin & Markup Calculator | Margin ↔ markup conversion, break-even analysis, Excel template |
| Marketing | ROAS Calculator | Basic, break-even, and target-ROAS planning |
| Finance | Compound Interest Calculator | Inflation-adjusted growth projections |
| Finance | Full Finance Suite | Loans, mortgages (PMI + taxes), savings goals, debt payoff |
| Health | TDEE Calculator | 3 medical formulas, calorie targets, macros |
| Math | Percentage Calculator | 6 modes incl. price increase/discount checks |

## Selection criteria

Every tool listed on the site meets four requirements:

- ✅ **No sign-up walls** — works instantly in the browser
- ✅ **Transparent formulas** — the math is verifiable, not a black box
- ✅ **Real-world examples** — not just bare input fields
- ✅ **Privacy** — calculations run locally, no data tracking

## Tech

- Single static HTML page — no frameworks, no build step, no JavaScript dependencies
- Zero tracking, zero ads, zero cookies
- Hosted free on **GitHub Pages**

## Run locally

No build required — just open `index.html` in a browser, or serve it:

```bash
# any static server works, e.g.
python -m http.server 8000
# then visit http://localhost:8000
```
